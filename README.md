# 📚 Library API - Spring Boot

## 📖 Descripción
**Library API** es un proyecto desarrollado en **Spring Boot** que permite gestionar de forma eficiente los recursos de una biblioteca.  
El sistema ofrece funcionalidades para administrar **usuarios, libros, préstamos y devoluciones**, garantizando una mejor organización y control de los registros bibliotecarios.

## 🎯 Objetivos
- Facilitar la administración de libros en la biblioteca.
- Registrar y gestionar préstamos y devoluciones.
- Controlar usuarios y roles para diferentes niveles de acceso.
- Exponer un conjunto de **endpoints RESTful** para la integración con otros sistemas o aplicaciones.

## 🛠️ Tecnologías Utilizadas
- **Java 24**
- **Spring Boot 3+**
- **Spring Data JPA** (para la persistencia en base de datos)
- **H2** (Base de datos relacional)
